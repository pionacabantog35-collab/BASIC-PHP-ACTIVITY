Basic PHP Activities

A collection of simple PHP programs built as part of hands-on PHP activities/exercises, practicing core language fundamentals and server-side scripting basics.

**Description**

This repository contains a set of small PHP scripts (program1.php, program2.php, etc.) used to practice fundamental PHP concepts such as:

Variables and data types

Output statements (echo, print)

Conditional statements (if, else, switch)

Loops (for, while, foreach)

Functions

Arrays

String manipulation

Basic form handling ($_GET / $_POST)

Basic input validation

** Note
**
These files were created as basic exercises to practice PHP fundamentals and local server setup using XAMPP.
