Basic PHP Activities

A collection of simple PHP programs built as part of hands-on PHP activities/exercises, practicing core language fundamentals and server-side scripting basics.

 Description

This repository contains a set of small PHP scripts (program1.php, program2.php, etc.) used to practice fundamental PHP concepts such as:

Variables and data types
Output statements (echo, print)
Conditional statements (if, else, switch)
Loops (for, while, foreach)
Functions
Arrays
Basic form handling ($_GET / $_POST)
🛠️ Requirements
PHP (tested on PHP 8.2.12)
XAMPP (or any Apache + PHP local server stack)
A web browser
🚀 How to Run
Option 1: Using XAMPP
Install XAMPP.
Copy this project folder into your htdocs directory:
   C:\xampp\htdocs\basic-php-activities\
Start Apache from the XAMPP Control Panel.
Open your browser and go to:
   http://localhost/basic-php-activities/program1.php

(replace program1.php with the file you want to run)

Option 2: Using PHP's Built-in Server
Open a terminal in the project folder.
Run:
bash
   php -S localhost:8000
Open your browser and go to:
   http://localhost:8000/program1.php
